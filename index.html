How the tool works

  1. Properties. Import the asset list or add properties by hand. Locate each one on the map, trace the rooftop(s) and enter floors to get built area, and trace the parcel boundary to get land area. Areas can also be typed in. Add photos for identification and appeals.
  2. Characteristics. Define the externally observable features (wall, roof, road access, structure type, and so on). Keep the list short and the categories few; merge rare categories.
  3. Sample values. For a sample of properties (LoGRI experience: 2–10 % of the stock, and at least a few dozen), a registered valuer enters a land value and an improvement value. Other properties are left blank.
  4. Models and weights. The tool fits ordinary least squares regressions of value on area and characteristics, one for land and one for improvements, and shows the weights with their statistical confidence and the fit statistics (R², RMSE, leave-one-out RMSE, COD, PRD). Any weight can be locked to a value chosen by the council; the tool then refits the remaining weights around it and shows the cost in R².
  5. Valuation roll. The formula is applied to every property. Land, improvement and total values are exported separately, together with a per-property calculation sheet that a taxpayer can check by hand.

Model forms

  • Log-linear (default): ln(value) = base + w × area + Σ feature weights. Weights read as percentages. Each extra square metre multiplies value by the same factor, so value grows exponentially with area; check the fit at large areas.
  • Log-log: ln(value) = base + w × ln(area) + Σ feature weights. The area weight is an exponent (0.5–1 is typical), which is the form used in LoGRI's guidance note and the Sierra Leone systems.
  • Linear: value = base + w × area + Σ feature amounts. Everything in currency.

Use "Compare forms" on each model to see R², RMSE and COD side by side before choosing.

Legal points to keep visible

  • LGA 1998 s.67 and Property Valuation Act 2024: valuation rolls must be prepared by a registered valuer. This tool supports a valuer's work; it does not replace the valuer's statutory role or certification.
  • LGA s.68(1): every roll must show total value, land value and improvement value separately. The export does this.
  • LGA s.68(2): post-2017 the basis is estimated rental value. The value basis setting records which basis the sample values use; use one basis consistently.
  • Condition variables: the Act's "reasonable condition" wording leaves it unclear whether actual condition may enter the formula. Characteristics marked as condition variables raise a flag.
  • PVA 2024 s.42 and Board approval: formal sanction of a mass-valuation method depends on ministerial regulations and Board of Valuers approval that were not confirmed as issued. The near-term route is a pilot on council-owned estates through an LGA s.66 supplementary roll.
  • LGA s.73: valuers need not inspect interiors, which supports the exterior-only characteristic list used here.

Data and privacy

Everything stays in this browser (IndexedDB) until you export it. Use "Save project" regularly and keep the file on council storage. Photos are resized to about 1024 px before storage. Satellite imagery needs an internet connection; everything else works offline.
